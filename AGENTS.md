# Project agent instructions

## Read by task

The local `docs/` directory is optional in a source checkout. Read the applicable guides when
available. Use [GLOSSARY.md](GLOSSARY.md) for domain terms and [README.md](README.md) for the demo
and build entry points.

- Before domain exploration or implementation, read `ignore-docs/agents`, then the relevant
  requirements in `ignore-docs/SPECIFICATION.md` and decisions in `ignore-docs/adr`.
- For implementation, debugging or validation, read `ignore-docs/agents`.
- For the `config.yml` server layout, read `ignore-docs/QUICKSTART.md`. For the separate `compose.yaml`
  host-profile layout, read `ignore-docs/DOCKER-DEPLOYMENT.md`.
- For backup or restore work, read `ignore-docs/BACKUP-RESTORE.md`.
- For native builds, client upgrades or source delivery, read `ignore-docs/BUILDING.md`.
- For PDF/font changes, read `ignore-docs/report-font.md`. For complaint-category changes, read
  `ignore-docs/reference-complaints.md`.

## Local tracker

Track specs and tickets under ignored `.scratch/`. When the guides are available, read
`ignore-docs/agents` for ticket changes and `ignore-docs/agents` for status changes.
